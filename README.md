# A Landscape Classification Framework for NP-Hard Problems: From Reconnaissance to Algorithm Selection (Version 7)

**Author:** tonyrao (饒滙盈)  
**Permanent DOI:** 10.5281/zenodo.19510539

## 📌 Overview
This repository hosts the official technical monograph for classifying NP-hard problems based on loss landscape topology[cite: 41, 42]. Rather than relying on trial-and-error, this framework establishes an **AI-executable protocol** spanning a 7-box taxonomy, a 3-tier reconnaissance system, a 5-cut decision tree, and a 10-step pre-solving pipeline[cite: 42].

## 📂 Contents
- `NP_Landscape_Classification_v7_tonyrao_2026.pdf`: The complete 60-page Version 7 technical monograph[cite: 1, 3].

## 🤖 AI-Executable Protocol Usage
As detailed in Section 16.4 of the monograph, this framework is table-driven and mechanisable. You can feed this PDF directly into an LLM (such as Claude, ChatGPT, or Cursor) along with your NP-hard problem instance to automatically generate the complete reconnaissance, difficulty scoring, algorithm selection, and parameter configuration pipeline.
